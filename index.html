SOBRE MÍ

Me interesa el detalle que hace que algo se sienta real.

Soy Lii Méndez. Trabajo en desarrollo web y me estoy formando en datos y bases de datos. Me gusta estar en el medio de las dos cosas: por un lado, crear interfaces que se vean bien y se sientan bien de usar; por el otro, entender cómo se guardan, se ordenan y se usan los datos que hay detrás.

Empecé con HTML y CSS, haciendo proyectos desde cero para aprender de verdad cómo funciona cada cosa, y después sumé JavaScript y Java con Spring Boot para poder hacer aplicaciones completas: no solo la parte que se ve, sino también la API, la lógica y el manejo de datos.

En mis proyectos cuido mucho los detalles que a veces pasan desapercibidos: que un piano suene con su frecuencia real, que una madera se vea como madera de verdad, que un blog tenga identidad propia y no parezca una plantilla, que un formulario sea claro y cómodo de completar. Para mí, que funcione no alcanza — tiene que sentirse bien usarlo.

Me gusta aprender haciendo. Cada proyecto de este portfolio nació de algo que quería entender mejor: cómo se hace un blog con estilo editorial, cómo suena una nota con Web Audio, cómo se construye una API REST, cómo se publica todo en GitHub Pages.

Ahora estoy buscando oportunidades donde pueda seguir creciendo como desarrolladora, en datos / DBA, o en un rol mixto que combine las dos áreas. Me interesa trabajar en equipos donde pueda aprender, aportar y seguir sumando proyectos reales.

Qué estoy buscando
